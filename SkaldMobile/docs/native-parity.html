Три вывода

  1. Механика уже близка. Коммит буквы по отпусканию, попап, скольжение с shift и 123, повтор backspace, точка по двойному пробелу, трекпад — всё есть; расхождения в цифрах (задержки, каденции) и в четырёх мелких правилах, которые правятся за день.
  2. Главный разрыв — не качество исправлений, а их подача. У Apple строка подсказок показывает, что именно сделает пробел, и это решение принято до нажатия. У нас исправление считается после пробела и не показано заранее. Отсюда ощущение задержки и «сюрпризов». Это правится без новой модели.
  3. Для русского и украинского Apple сама работает по старой схеме. Трансформер, встроенные предсказания, QuickPath для украинского и двуязычный ввод для кириллицы у Apple недоступны. Наша биграммная модель и переключение RU⇄UK⇄EN свайпом — уже больше, чем даёт система. Догонять надо в мелочах, а не в архитектуре.

00Потолок: что стороннее расширение не может по правилам iOS

Это не наши недоработки, а ограничения платформы, подтверждённые документацией Apple. Гнаться за ними бессмысленно; важно знать их, чтобы не обещать.

  • Рисовать в поле ввода. Расширение рисует только внутри своей области. Поэтому нет серого встроенного предсказания, нет красного подчёркивания ошибок, нет подчёркивания исправленного слова с меню по тапу. Всё это у нас переезжает в строку подсказок.
  • Выделять текст. Есть только перемещение каретки на N символов. Второй палец в трекпаде, двойной тап двумя пальцами, меню «Вырезать/Копировать» из клавиатуры невозможны.
  • Видеть весь текст. Контекст ограничен текущим абзацем и устаревает после вставки или ввода с другой клавиатуры. Мягкие переносы строк невидимы, поэтому вертикальный трекпад по визуальным строкам можно только оценивать.
  • Пароли и телефонные поля. Система сама подменяет нас своей клавиатурой.
  • Системные штуки. Диктовка Apple, системная панель эмодзи и Memoji, открытие приложения из клавиатуры (сломано с iOS 18 и запрещено гайдлайнами), чтение системных настроек клавиатуры. Микрофон в нижней системной полосе на iPhone с Face ID при этом работает и с нашей клавиатурой.
  • Без Full Access: нет сети, буфера обмена, хаптика и записи в App Group. Клавиатура обязана работать и без него (правило App Review 4.4.1).
  • Память: около 60 МБ, при превышении процесс убивается молча. Наш словарь одного языка занимает около 10 МБ, держим не больше двух.
  • Входные данные Apple. Система исправляет не по тексту, а по касаниям: точки нажатий, скрытое расширение зон вероятных клавиш (патент US 8,232,973), контекст получателя и приложения. Из готового текста это не воспроизвести, но точки касаний мы можем записывать сами.

→План закрытия разрыва

Порядок по соотношению «насколько заметно пользователю» к «сколько работы». P0 закрывается за один-два дня и меняет ощущение сильнее всего.

P0Ощущение системной

1–2 дня
  • Строка как у Apple: кандидат считается во время набора с дебаунсом 120–150 мс, показывается подсвеченным в центре; пробел, знак и Return применяют ровно его. Слева всегда набранное в кавычках, когда оно отличается. Убирает и задержку, и «сюрпризы».
  • Return как триггер автозамены; заглавная после Return.
  • Backspace: 500 мс старт, слова после 20 символов по 350 мс.
  • Наложение касаний: второе касание фиксирует первую букву.
  • Скольжение с ABC/#+= возвращает страницу; попап 70 мс; долгое нажатие 0,45 с; трекпад 0,45 с.
  • numbersAndPunctuation открывает 123.

P1Качество исправлений

3–5 дней
  • Точки касаний в скоринге: хранить смещение пальца по каждой букве текущего слова и взвешивать кандидатов близостью. Это главный рычаг, которым пользуются и Apple, и Grammarly.
  • Сокращения и апострофы для EN (dont, cant, im, ive, youre…), апостроф в алфавите правок для всех раскладок, i → I.
  • Умная пунктуация по языку раскладки: « » / “ ”, «--» → «—», ’.
  • Имена из Контактов через UILexicon в личный словарь; защита слова пустым шорткатом; кнопка «Сбросить выученные слова» в приложении.
  • Не исправлять повторно слово, которое пользователь только что перенабрал; не перевзводить shift после ручного выключения.
  • Трекпад: ускорение от скорости, 5–6 pt на символ, осветление клавиатуры.
  • Решение по backspace (см. ниже).

P2Детали

по мере сил
  • Динамические зоны попадания по вероятности следующей буквы из префиксного словаря.
  • Три звука клика вместо одного (с оговоркой: системные ID обходят настройку звука).
  • Поиск эмодзи и оттенки кожи; .com по долгому нажатию в URL-полях; наклон попапа у краёв; приглушённый Return при пустом поле; высота в ландшафте 162 pt.

P3Большие куски

недели
  • QuickPath: свой декодер жестов; у Apple для украинского его нет, для русского есть.
  • Режим одной руки.
  • Догрузка словарей в приложении, если языков станет больше трёх.
Одно решение за тобой: что делает backspace сразу после автозамены.
Нативно он просто удаляет пробел, а набранное слово снова появляется слева в строке подсказок; чтобы вернуть его, нужен второй тап. У нас backspace возвращает набранное сразу и запоминает его. Наш вариант быстрее, системный привычнее. Если цель «не отличить от системной», переключаемся на системный: удаляем пробел, показываем оригинал в строке, обучаем по тапу.
